# C-E4：目标域适应样本量敏感性（target_adapt = 50 / 500 / 5000 / 45000）

> **一句话结论（待 results 完成后回填）**：待补。

## 8.1.1 实验级别与目标

- **级别**：formal（3 seeds × 3 预算 × 3 方法 + 已有全量档复用；第一阶段 desync50，第二阶段 desync100 视时间）。
- **要回答的问题**
  1. 最少需要多少条目标域**无标签**适应轨迹，才能恢复密钥（稳定 GE=0）？
  2. CDAN-SCA full 是否存在"少样本生态位"——在 50 / 500 档达到 3/3 稳定 GE=0 且总成本低于领域强基线 CDPA-MMD？
  3. 以总成本 `N_total@GE=1 = budget + N_attack@GE=1` 为主判据时，哪种方法最优？少样本时 CDPA-MMD 的 MMD 是否比对抗方法更鲁棒？
- **假设**
  - H1：适应样本减少会同时降低所有方法的上限，`NTGE` 与 `N_total` 都变差；但对抗方法（DANN / CDAN-SCA）因判别器可过拟合到极少样本，退化更快。
  - H2：CDPA-MMD 在 50 / 500 档比对抗方法更稳（MMD 是对分布统计量，不训练判别器）。
  - H3：CDAN-SCA 的熵权重会放大少样本下的坍塌（w≈1 把对抗项集中到"自信但错"的样本），坍塌更早、更重。
  - H4：把适应成本计入后，少样本方法即使 NTGE 相当也可能因 budget 更小而占优；但若 50 条就坍塌，则总成本口径也救不了。
- **判定规则（事先写定）**
  - 生态位成立：CDAN-SCA full 在 50 或 500 档 **3/3 稳定 GE=0** 且同档 `N_total@GE=1` 均值 **低于 CDPA-MMD**。
  - 最少适应轨迹：某方法 stable rate 首次从 0 变为 ≥1/3 的预算（另报首次达到 3/3 的预算）。
  - 主判据是总成本；NTGE 打平但 N_total 明显更高判"未胜出"。

- **不混用**：target_adapt 取自 Profiling_traces，target_attack 取自 Attack_traces，天然不重叠；此外子集索引全部 < 45000，`train_budget.py` 加载时断言 `max(idx) < 45000`，不会侵入 target_domain_val。
- **子集共享**：`configs/target_subsets.json`（sha256 `0936b2a62d5d84aef5104ff2e3e93c5fc3bfab402be19272faec9c3ae68d49d2`）记录每个 (shift, seed) 的 50 / 500 / 5000 索引，**嵌套**（50 ⊂ 500 ⊂ 5000），三种方法在同 seed 下使用完全相同的轨迹子集。
- **适应标签**：target_adapt 的标签只在训练结束后用于 ECE / confident-wrong 诊断，不参与损失与模型选择（`run_meta.json` 中注明）。
- **成本双口径**：`N_attack@GE=1` = 首个 GE=0 的攻击轨迹数；`N_total@GE=1 = budget + N_attack@GE=1`。本实验明确把 target_adapt 计入 N_total，并以 N_total 为主判据。

## 8.1.4 实现与协议（只改变一个变量）

- 主干与初始化：`OfficialCNN`（`experiments/00_common_e0/scripts/train_e0_torch.py`），逐 run 加载 **B-E1 同 seed** 的 `cnn_s<seed>/ckpt.pt` 初始化（与 A-E2/A-E3/B-E3 一致）。
- 冻结配方：RMSprop `lr=1e-5`、batch 200、75 epochs、原始 int8 幅度输入（不归一化、无 BN）。
- **唯一变化**：target_adapt 条数。
- **源域训练量对齐**：每 epoch 仍是 `ceil(45000/200)=225` 个 batch；目标域每 epoch 也取 225 个 batch（45000 个目标样本位置）。预算小于 45000 时，目标索引按独立随机置换**循环采样**拼接截断（`epoch_target_indices`），因此三种方法在同一 seed 下看到的目标索引序列完全一致，且"每 epoch 目标 batch 数 / 源域样本数"不随预算变化。
- 损失（与既有 trainer 逐行一致）：
  - DANN：`CE(src) + BCE_src + BCE_tgt`（判别器输入为 L2 缩放特征）。
  - CDAN-SCA full：`CE(src) + BCE_src + mean_t[w * BCE_tgt]`，`w = 1 - H/log(256)` 且 detach，判别器输入 `T(f,g)`（proj 1024）。
  - CDPA-MMD：`CE(src) + 0.1 * Σ_layers MMD(conv, fc1, fc2)`（5 核 RBF，带宽按批内平均距离）。
- 监控与产物：每 epoch 在子集（≤2000 条）上算 top1 占比 / 预测熵 / w 分布，`>30%` WARN、`>50%` COLLAPSE；每 2 epoch 500 条 attack GE 探针；结束时保存 `predictions_attack.npy`、`history.json`、`run_meta.json`、`diag_target_adapt.npz`、`entropy_diag.json`、`domain_diag.json`（对抗方法）/`grad_probe.json`（CDPA）。ckpt 存 `sca_repo/outputs/models/c_e4/<run>/ckpt.pt`。
- 训练脚本：`scripts/train_budget.py`；子集生成：`scripts/make_subsets.py`；评估/聚合/置换/绘图见 `scripts/`。

**与既有实验的差异**：A-E3 的 CDPA 每 epoch 用全量 45000 条，本实验 50/500/5000 档是同一优化步数下的重复采样；这会改变 MMD 估计的方差，但这是"少样本"本身的效应，不做额外平滑。

## 8.1.5 成本与运行

- 单 run：75 epochs × 约 24–27 s ≈ 28–34 min（RTX 5060 Laptop，源域 45000 条不变）。
- 45000 全量档不重跑，复用 A-E3 / A-E2 / B-E3 / B-E2 的结果。
- 实际：desync50 27 run 合计 **49,065 s = 13.63 GPU·h**；desync100 27 run 合计 **48,733 s = 13.54 GPU·h**；两阶段共 **27.17 GPU·h**（逐 run 见 8.1.10）。

## 8.1.8 少样本生态位判定

预设判据：主方法（CDAN-SCA full）在 50 / 500 档 3/3 稳定 GE=0，且 N_total 低于 CDPA-MMD 同档。

判定：**两个 shift 都不成立**。

- desync50：50 档 CDAN-SCA full **0/3 触发**（GE@10k 13.67），N_total 下界 10050 > CDPA-MMD 8050；500 档 1/3 触发，8467 > 5233（高 61.8%）。CDPA/ CDAN 的 N_total 比值 0.80（50）、0.62（500）、0.81（5000）、0.99（45000）——预算越少，对抗 + 熵加权越吃亏。
- desync100：50 档 CDAN-SCA full 1/3 触发（N_total 9383）vs CDPA 2/3 触发（3883，且不可复现）；500 档 7867 vs 7233；5000 档 11867 vs 8733；45000 档 51000 vs 48700。CDPA 仍然全面更低。
- **归因**（表 C，见 8.1.9）：CDAN-SCA full 的目标域 top-1 单类占比在 desync50@50 达 0.733、desync100 四个预算档全部 ≥ 0.791（35.3–39.7 个 epoch 处于坍塌），ECE 0.927–0.956、confident-wrong 0.850–0.908；同预算下 CDPA-MMD 的 top-1 只有 0.037–0.087、0 次坍塌、ECE 0.646–0.717。少样本时熵权重把"自信但错"的目标样本放大（w→1），判别器进一步推高置信度，形成自我强化；MMD 只在特征层做矩匹配，没有这条正反馈路径。

## 8.1.12 结论与适用边界

回答任务提出的三个问题：

1. **最少多少条适应轨迹能恢复密钥**：desync50 是 **500 条**（CDPA-MMD@500：3/3 首次触底、4733 ± 694 条攻击轨迹、2/3 稳定、置换均值 3530 与原始值同量级）；desync100 **没有可用答案**——所有 (方法, 预算) 组合的稳定率都 ≤ 1/3，名义最低的 50 条档（CDPA 3883）经置换检验证伪（700/800 的零点重排后不复现）。
2. **主方法是否有少样本生态位**：没有。CDPA-MMD 在两个 shift、四个预算档的 NTGE 与 N_total 全部最低；CDAN-SCA full 没有任何一档 3/3 稳定，desync50 的 50/500 档 N_total 下界比 CDPA 高 24.8% / 61.8%。在总成本口径下，CDAN-SCA 的对抗项 + 熵加权在少样本与强域偏移时都是负担：desync100 上它在四个预算档持续坍塌 35–40 个 epoch。
3. **总成本口径谁最优**：desync50 → CDPA-MMD@500（5233 条，相对 45000 档省 89.7%）；若要求 3/3 稳定 → CDPA-MMD@5000（12533，省 75.6%）。desync100 → 可信最优是 CDPA-MMD@45000（48700 首触 / 54233 稳定）；低预算档的"更低成本"是瞬时零点造成的下界，不能采用。

**方法学结论**：目标域样本量不是单调有益的资源。desync50 上 500 条比 50 条好、比 5000/45000 更省；desync100 上增加或减少适应样本都无法把稳定率推过 1/3。判断"某预算够不够"必须同时看首触与稳定两个口径，并做轨迹顺序置换，否则会把顺序幸运读成方法收益。

**边界**：ASCAD v1 单一数据集、fixed→desync50/100 两个采集偏移；attack 上限 10k 使大量 cell 截尾（截尾值只作下界）；3 seeds；NTGE 对轨迹顺序敏感（8.1.10）。"跨设备"结论仍未验证（desync 只是同一芯片的采集偏移），不能用本实验结果支撑跨设备域适应。

## 8.1.13 下一步实验

1. **5 seeds + bootstrap CI**：对 desync50 的 500 档与 desync100 的 5000/45000 档各补 2 个 seed，给 N_total 的 95% CI，确认 desync50 的"500 条拐点"与 desync100 的"1/3 稳定上限"不是 seed 抽样波动。
2. **λ_adv = 0 同 ckpt 对照**（6 run，约 3.2 GPU·h）：固定 B-E1 初始权重、75 epoch、不加对抗项，把"少样本时的收益"与"对抗项"彻底分离——这是目前唯一缺失的归因。
3. **把轨迹顺序稳健性纳入正式口径**：主表改用 K=10 次置换的均值±sd（只增加评估时间、不训练），并在所有后续实验中默认报告置换均值，避免再出现 desync100 那类"700 条"误读。
4. **换数据集验证**：CDPA / variable-key 系列，当前 fixed→desync 只是采集偏移，不足以支撑"跨设备"。
5. **追查 desync100 的失败机理**：CDPA 在 desync100 上 3/3 的首触消失、稳定率只有 1/3，而 desync50 是 3/3；建议做 target_adapt 与 target_attack 的表示距离（MMD/ CMD）随预算的变化，确认是"适应样本不足"还是"偏移超出 MMD 的可对齐范围"。
6. **若坚持 CDAN-SCA 主线**：先修少样本与强偏移下的过自信（温度校准 / 熵下限 / 权重截断），并以"3/3 稳定 GE=0 且 N_total 低于 CDPA-MMD 同档"作为准入门槛；当前证据不支持把它作为主方法。
