# B-E3 报告：CDAN-SCA full 与熵权重诊断（ASCAD fixed-key -> desync50/desync100）

- 实验编号：B-E3（主方法）+ B-E4（三向消融）
- 实验级别：formal（6 次 full + 6 次消融 1；消融 2 = A-E2 的 CDAN 6 次复用）
- 归档目录：experiments/02_member_b_method/b_e3_cdan_sca/（消融汇总在 b_e4_ablation/）
- 主干：Official CNN（B-E1 同 seed 权重初始化）
- 本报告由 README.md 的 8.1.1-8.1.13 自动生成，内容与 README 一致。

本目录实现并验证项目主方法 **CDAN-SCA full**（条件域对抗 + 归一化熵权重），
与 **消融 1**（去条件输入、仅保留熵权重的边缘对齐）同矩阵训练；**消融 2 = CDAN**
直接复用 A-E2 的 6 个 run，不重跑。三向对照与五方法总表在 `b_e4_ablation/`。

**一句话结论**：CDAN-SCA full 在两个偏移上都没有达到任务书门槛，也没有胜过领域基线 CDPA-MMD——desync50 NTGE 6000（3 个 seed 中仅 1 个稳定触底）对 CDPA-MMD 的 5700（3/3 稳定）；desync100 GE@10k 8.67 / NTGE 6000（0/3 稳定）对 CDPA-MMD 的 4.0 / 3700。熵权重在目标域预测已塌缩（熵 ≈0.13 nats，w≈0.98）时几乎不起作用：full 的校准与 CDAN 无统计差别（ECE 0.945 vs 0.944、confident-wrong 0.861 vs 0.857），6/6 full run 仍出现 top1 单类占比 >30% 的坍塌；消融 1（去条件输入）能把坍塌压到 0.16–0.43，却再也换不来稳定的 GE=0，且 NTGE 对轨迹顺序极敏感（full d50 s42：800 → 置换 2310±1422）。

#### 8.1.2 目标与假设

主问题：**条件域对齐 + 熵加权在 SCA 上是否优于已有基线**。不追求理论最优，只要求同条件下
胜过最强基线（CDPA-MMD）；若失败，用诊断数据归因，不为凑结果反复调参。

1. **H1（熵权重抑制坍塌）**：CDAN 在 desync100 上出现预测坍塌（top1 单类 36.6–58.7%、
   ECE 0.94、confident-wrong 85–86%）。低熵目标样本获得更大对抗权重，若这些样本恰好是
   重复的少数类，则熵权重会**强化**坍塌；若低熵主要来自真实判别性样本，则应缓解。
   两种方向都可能，按实测判定。
2. **H2（条件化的独立贡献）**：full 与消融 1 的唯一差异是判别器输入 T(f,g) vs f；
   两者都带熵权重。该对比隔离“类别条件化”本身，不把 DANN 当消融。
3. **H3（相对最强基线）**：按硬性判据（8.1.12）比较 NTGE / GE@10k / SR 与双口径轨迹成本；
   若 NTGE 打平但 N_total 更高，记为未胜出。

#### 8.1.4 方法定义与实现

严格按 `docs/research/主方法.md` 与任务书，**不自行改动**：

    L = L_cls(source) + BCE_src + mean_t[ w(g_t) * BCE_tgt ]
    w(g) = 1 - H(g) / log(256),   H(g) = -sum_k g_k log g_k  (nats)
    T(f, g) = (Rf^T f_unit * sqrt(d)) ⊙ (Rg^T g)      # 随机多线性映射，d = proj_dim = 1024

- 主干/分类器：Official CNN 的 convs + fc1 + fc2（4096 维特征）+ fc3（256 类），
  与 A-E2 的 DANN/CDAN 完全同一实现（`uda_common.UDANet`），初始化来自 B-E1 同 seed checkpoint。
- GRL：`grad_reverse(z, lambda_adv)`，λ_adv = 0.1（与 A-E2 的 DANN/CDAN 完全一致）。
- 熵权重只作用于**目标域**的域对抗损失；w 由 `softmax(logits_t).detach()` 计算，
  不向分类器回传梯度（避免权重与分类器互相博弈）。
- 判别器损失：源域 BCE 取 batch 均值，目标域 BCE 逐样本乘 w 后取 batch 均值
  （即 `(w * bce_t).mean()`，不额外按 w 归一化；早期 w 小则目标域对抗信号弱，这是方法本身的行为）。
- **消融 1（marginal）**：判别器输入改为 L2 缩放特征 f（DANN 式边缘对齐），其余（含熵权重）不变。
- **消融 2（CDAN）**：A-E2 的同配方、无熵权重版本，直接复用，不重跑。
- **禁止混用**：`experiments/legacy/CDAN/dann.py` 的指数权重是另一实现，本实验不使用；
  代码中只有 `cdan_sca_common.entropy_weight` 一个熵权重公式。

与 A-E2 的唯一差异（除方法名）就是目标域域损失的熵权重；数据、主干、优化器、λ、epoch 数、
批大小全部相同。CDAN-SCA full 相对 CDAN 的**唯一变量**即熵权重。

#### 8.1.5 训练配方、监控与成本

| 项 | 值 |
|---|---|
| 优化器 | RMSprop，lr=1e-5 |
| batch | 200（source 200 + target 200） |
| epochs | 75（不早停） |
| 输入 | 原始 int8 幅度，不归一化 |
| λ_adv | 0.1（GRL） |
| proj_dim | 1024（full；marginal 无 T） |
| 参数量 | full 68,227,457（含判别器 1.57M）；marginal 71,373,185 |
| checkpoint | 每 5 epoch 覆盖写 `outputs/models/b_e3/<run>/ckpt.pt`（约 533 MB/run） |
| GE 探针 | 每 2 epoch，500 条攻击轨迹，step=100（只记录） |

**训练期监控（针对预测坍塌，每 epoch）**：在 target_adapt 固定前 2000 条上计算
top1 单类占比、预测熵（nats）、熵权重 w 的均值/分位数、预测类别数；同时记录源域 CE、
域判别源/目标准确率、GE 探针。规则：top1 占比 >30% 打 `WARN`、>50% 打 `COLLAPSE`，
写入 `history.json` 的 `collapse_flags` 与训练日志；**不提前终止**，保留 75 epoch 证据。

**产物**：每 run 保存 `predictions_attack.npy`（10000×256）、
`diag_target_adapt.npz`（前 5000 条适应集的 probs/labels/entropy/w，标签仅诊断）、
`entropy_diag.json`（适应集 ECE/confident-wrong/top1）、`history.json`、`run_meta.json`、
`domain_diag.json`（训练前后域判别 balanced acc）。

**成本**：每 run 75 epoch / 约 1700–2100 s；12 run 约 5.8 GPU 小时；评估每 run 约 5 s。

#### 8.1.8 汇总表与胜负判定

任务书门槛：**d50 = NTGE ≤ 5700 且 3/3 稳定 GE=0；d100 = GE@10k ≤ 4.0 且 NTGE ≤ 3700**。
“稳定”指触底后不再回升（`ntge_stable`）；NTGE 打平但 N_total 更高记未胜出。

| 场景 | full 实测 | 门槛 | 判定 |
|---|---|---|---|
| desync50 | NTGE 6000，稳定 1/3，GE@10k 7.67 | ≤5700 且 3/3 | **未胜出**（NTGE 高 300，稳定差 2 个 seed） |
| desync100 | GE@10k 8.67，NTGE 6000，稳定 0/3 | ≤4.0 且 ≤3700 | **未胜出**（两项都差一倍以上） |

配对比较（逐 seed 的 NTGE 差，负值=full 更好；截尾按 10000 计）：

| 对手 | d50 Δmean（胜/平/负） | d100 Δmean（胜/平/负） |
|---|---|---|
| Source Only | −4000（2/1/0） | +2300（0/1/2） |
| DANN | −3166.7（2/1/0） | −2300（1/1/1） |
| CDAN | −4000（2/1/0） | −566.7（1/1/1） |
| CDPA-MMD | +300（1/0/2） | +2300（0/1/2） |
| 消融 1 | −1533.3（2/1/0） | +1400（1/0/2） |

结论：full 相对 CDAN/DANN 只是“略有改善且不稳定”，相对 CDPA-MMD **两个场景都输**；
在 d50 上即使只看最好的 seed（800），CDPA-MMD 也是 3/3 稳定，按“稳定性优先”仍判 CDPA-MMD 胜。

消融读数：
- **条件化**（full vs 消融 1）：d50 全面更好（NTGE 6000 vs 7533、SR 0.33 vs 0、稳定 1/3 vs 0/3）；
  d100 则相反（NTGE 6000 vs 4600、GE@10k 8.67 vs 18.0），但两者都 0/3 稳定。条件化在 d100 上
  把“中段塌陷”换成了“起步塌陷”，并没有解决失败模式。
- **熵权重**（full vs CDAN）：d50 NTGE −4000、d100 −566.7，方向为正但方差异常大；
  校准上没有收益（8.1.9），所以这点“改善”不能归因于熵加权本身，更可能是条件化+多训的混合效应。
- 2×2 缺格（无权重+无条件 = DANN）在 d50 是 9166.7（1/3 稳定），说明**单加条件化或单加权重
  都不足以跨过门槛，两个一起加也只到 6000/1-of-3**。

#### 8.1.9 熵权重诊断（本实验第二核心产出）

但注意 d100 s44 的消融 1 也在 epoch ~30 冲到 0.5465——**去条件化只能缓解、不能根除**。

**(c) 三问的答案**

1. **是否减少坍塌？没有。** full 6/6 run 均出现 top1>0.30，d100 有 30–41 个 epoch 处于 >0.50；
   终点 top1（0.469）与 CDAN（0.484）几乎一样。
2. **是否改善校准？没有。** full 的 attack ECE/confident-wrong 在 d100 为 0.945/0.861，
   CDAN 为 0.944/0.857（差 0.001/0.004，小于 seed 间波动）；d50 甚至比 CDAN 更差
   （0.867/0.655 vs 0.846/0.597）。CDPA-MMD 在两个场景都最好（0.72–0.73 / 0.33–0.36）。
3. **是否带来 GE/NTGE 收益？有限且不可归因。** 相对 CDAN 的 NTGE 差为 −4000（d50）/−566.7（d100），
   但 d100 上 full 的 GE@1k 反而从 29.67 恶化到 51.33；相对 CDPA-MMD 两场景都输。

**(d) 机制：熵权重在塌缩后饱和失效。** w = 1 − H/log(256)。d100 full 的 adapt 侧
H=0.132 → w≈0.976，CDAN H=0.140 → w≈0.975；w 的 90 分位在两方法都是 1.000，
10 分位 0.897 vs 0.891。也就是说**当模型已经“自信且错”时，熵权重把对抗信号几乎均匀地
施加到全部目标样本上，等价于没有加权**；它无法把权重从“自信但错”的样本上移开。
d50 的 H=0.332 → w≈0.940，权重分布稍宽，但方向仍是放大而非抑制——
这与“熵低 → 权重高 → 少数类获得更大对抗梯度 → top1 集中”的坍塌正反馈一致（H1 的“强化”分支成立）。
消融 1 的 H 更高（0.31–0.56），w 更低（0.90–0.94），坍塌确实更轻，但判别性也同时下降。

#### 8.1.10 攻击成本

- **训练成本**：12 个 run 合计 22,632 s = **6.29 GPU 小时**（full 1814.7/1885.7 s 每 run，
  消融 1 1916.7/1927.2 s 每 run；24–26 s/epoch）。A-E2 的 6 个 CDAN run 约 3.1 h 为前序成本，
  本实验不重复计入；评估/出图 < 10 分钟（CPU）。
- **攻击成本双口径**（N_attack@GE=1 与 N_total@GE=1，截尾 10000）：

| 方法 | d50 N_attack | d50 N_total | d100 N_attack | d100 N_total |
|---|---|---|---|---|
| CDPA-MMD | 5700 | 50700 | 3700 | 48700 |
| CDAN-SCA full | 6000 | 51000 | 6000 | 51000 |
| 消融 1 | 7533.3 | 52533.3 | 4600 | 49600 |
| CDAN | 10000 | 55000 | 6566.7 | 51566.7 |

  即使 full 在 d50 的 N_attack 只比 CDPA-MMD 多 300，N_total 仍多 300（每条适应轨迹都要采）；
  d100 多 2300。按“NTGE 打平但 N_total 更高判未胜出”，full 在两个场景都没有成本优势。

- **轨迹顺序敏感性（重要）**：对 7 个出现 GE=0 的 run 各做 10 次轨迹顺序置换
  （`results/permutation.json`），首次 GE=0 的轨迹数变化极大：

| run | 原顺序 NTGE | 置换均值±std | 置换范围 |
|---|---|---|---|
| full d50 s42 | 800 | 2310±1422 | 400–4600 |
| full d50 s43 | 7200 | 6960±3382 | 1800–10000 |
| 消融 1 d50 s42 | 2600 | 8650±3168 | 300–10000 |
| full d100 s42 | 7000 | 8360±3520 | 400–10000 |
| full d100 s43 | **1000** | **6710±4262** | 1000–10000 |
| 消融 1 d100 s42 | 3000 | 6960±2916 | 2200–10000 |
| 消融 1 d100 s44 | 800 | 8430±2692 | 2700–10000 |

  也就是说，**固定顺序下的单次 NTGE 不能当作稳定结论**：full d100 s43 的“1000 条”在置换后
  均值 6710；消融 1 d50 s42 的 2600 在 10 次里只有 1 次接近（300），其余多为 10000。
  报告主表仍按任务书口径给首次/稳定值，但解释胜负时必须同时看置换结果；据此 full 对 CDPA-MMD
  的差距只会更大，不会更小（CDPA-MMD 尚未做同样置换，列为下一步）。

#### 8.1.12 结论边界

可以下的结论：
1. 在本协议（ASCAD fixed-key → desync50/desync100、Official CNN、RMSprop 1e-5、75 epoch、3 seed）下，
   **CDAN-SCA full 没有达到任务书门槛，也没有胜过 CDPA-MMD**；d50 差 300 条且稳定性 1/3 vs 3/3，
   d100 的 GE@10k 与 NTGE 都差一倍以上。
2. **熵权重没有抑制预测坍塌，也没有改善校准**：full 的 top1 占比与 ECE/confident-wrong 与 CDAN
   基本重合；机制是目标域熵塌缩后 w 饱和到 ~0.98，加权退化为无权。
3. **条件化是 CDAN 家族内 NTGE 的主要来源**：full 比消融 1 在 d50 好（6000 vs 7533，稳定 1/3 vs 0/3），
   但在 d100 上被消融 1 反超（6000 vs 4600），说明它没有解决 d100 的失败模式。

不能下的结论：
- 不能说“熵加权在 SCA 上普遍无效”——只测了两个偏移、一个数据集、一个主干；
  也不能说“条件化无用”——d50 的证据支持它有用。
- 不能把单次 NTGE（尤其 <2000 的值）当成可复现的攻击成本；置换检验显示顺序效应可达数倍。
- 不能把 accuracy（0.003–0.006，均低于 1/256=0.0039 的量级附近）当作有效性证据。
- 本实验没有做超参搜索；若换 lr/λ/epoch，结论可能变化，但那属于新实验，不能混入本结论。

#### 8.1.13 下一步实验

1. **校准感知的 CDAN-SCA（最直接）**：把 w=1−H/log256 换成
   w'=(1−p_max)^γ 或对 p_max>0.9 且预测错误的样本降权/弃权；在 d100 上先做 1 个 seed 的 pilot，
   以 top1 占比与 ECE 为门控指标，再决定是否扩到 3 seed。当前诊断显示“自信且错”占 86%，
   这是唯一有明确机制依据的改动方向。
2. **先解决坍塌再谈对齐**：在 target_adapt 上以 top1 占比/熵设早停或回滚（不使用标签），
   比较“坍塌前 checkpoint”与 75 epoch 终点的 GE；这可判断 full 的失败是“训练过度”还是“方法本身”。
3. **把 NTGE 的置换均值作为主口径**：对 CDPA-MMD 的 6 个 run 补做同样的 10 次置换，
   再重排五方法胜负；否则“5700 vs 6000”这类 300 条差异没有解释力。
4. **换更强偏移/跨设备**：desync100 已接近方法失效边界；建议加 variable-key 或跨芯片数据，
   检验“熵权重饱和”是否是普遍现象。
5. **用 MMD 替换判别器做对照**：CDPA-MMD 是唯一不塌的方法，其多层 MMD 没有对抗判别器；
   可做 CDAN-SCA + MMD（条件 MMD）与 full 对照，验证“坍塌来自对抗训练而非条件化”。
